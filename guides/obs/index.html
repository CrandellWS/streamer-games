Put a free game on your stream in 2 minutes

Every game is one web page. Viewers see a clean overlay. You run it from a controller that only you see. No installs, no accounts, no cost.

The two addresses

Each game has two versions of the same address. Swap spin-wheel for the game you picked.

Overlay: what viewers see

https://homeofficestudios.com/spin-wheel/?admin=false&bg=transparent

No panel, transparent background. This goes in OBS as a Browser Source.

Controller: what you click

https://homeofficestudios.com/spin-wheel/?view=remote

The full control panel. Every button you press runs in the overlay. Keep this off stream.

Set it up

  1. Pick a game

    Open the games list and choose one. Spin Wheel or Marble Race are easy first picks.

  2. Add the overlay as a Browser Source

    In OBS, click + under Sources, choose Browser, and paste the overlay address.

    Set Width 1920 and Height 1080 to match a 1080p canvas, then resize it in the preview if you want it smaller.

  3. Open the controller in a dock

    In OBS go to Docks, then Custom Browser Docks. Paste the controller address and give it a name.

    The controller bar turns green when it finds the overlay. Add names and press Start there.

  4. Go live

    Space starts most games. Esc closes a win screen.

Controller says "waiting for the overlay"?

The overlay and the controller must run in the same browser. If your OBS dock and source will not connect, use one of these instead.

Window Capture

Open the overlay address in a normal browser window and add that window to OBS with Window Capture. Open the controller address in a second window of the same browser.

Interact

Right-click the Browser Source, choose Interact, and use the keyboard. Space starts most games.

Do not capture a tab that shows the control panel. In Number Guess the panel shows the secret number.

Let chat play: where your room key is

Some games take their moves from chat. Run those through Chat Play.

  1. Open Chat Play

    Click the Chat off button at the top left to open the setup panel.

  2. Find your key

    It is in the Your key box. A random one is made for you the first time. New random key replaces it.

  3. Copy the command

    Click Show Slot Tools command and paste it into Slot Tools as a command named play, permission Everyone.

The command contains your private key. Close the setup panel before Chat Play is on screen, and never show it on stream. If it leaks, press New random key and paste the new command.
