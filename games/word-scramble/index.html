Word Scramble

Scrambled letter tiles appear. first viewer to unscramble the word in chat wins. Built-in categories and hints. Chat plays it with !play. Free.

How chat plays

  1. Open Chat Play and pick Word Scramble. It runs the game and listens for chat.
  2. Viewers type: !play yourword to guess. !play count shows how many are in.
  3. You start the round from the game's admin panel. The winner shows on screen.

What you need

A Kick channel with the Slot Tools chat bot (one !play command, copied from the Chat Play page), and OBS or any streaming app with a Browser Source.

Browser Source URL, size 1920 x 1080 (or your canvas size):

https://homeofficestudios.com/chat/?game=word-scramble&admin=false&bg=transparent
