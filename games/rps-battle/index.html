Rock Paper Scissors

Tournament bracket elimination. Viewers pick R/P/S, animated hand reveals, last one standing wins. Chat plays it with !play. Free.

How chat plays

  1. Open Chat Play and pick Rock Paper Scissors. It runs the game and listens for chat.
  2. Viewers type: !play to enter, then !play rock / paper / scissors. !play count shows how many are in.
  3. You start the round from the game's admin panel. The winner shows on screen.

What you need

A Kick channel with the Slot Tools chat bot (one !play command, copied from the Chat Play page), and OBS or any streaming app with a Browser Source.

Browser Source URL, size 1920 x 1080 (or your canvas size):

https://homeofficestudios.com/chat/?game=rps-battle&admin=false&bg=transparent
