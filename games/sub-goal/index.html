Sub Goal

A sub goal bar for your stream: "Subs this month: 4 / 10", a bar that fills, and confetti with a chime when you hit it. You bump it with one click from an OBS dock. No login, no server, no Kick account linking. Free.

Open the overlay Open the control page

How it works on stream

  1. Add the overlay to OBS as a Browser Source.
  2. Add the control page as an OBS Custom Browser Dock (Docks, Custom Browser Docks).
  3. Someone subs, you press +1 in the dock. The bar moves. At the goal, confetti, a banner and a chime.
  4. The count is saved, so a refresh keeps it. It goes back to 0 on the 1st of each month, unless you add reset=off.

What you need

OBS (or any streaming app with a Browser Source and docks). The overlay and the dock must both run inside OBS so they can hear each other. Nothing reads Kick for you: you count the subs, so it never needs your login.

Browser Source URL, size 1920 x 1080:

https://homeofficestudios.com/sub-goal/?goal=10&admin=false&bg=transparent

Dock URL:

https://homeofficestudios.com/sub-goal/control.html

Make it yours

Add these to the overlay URL: label= for the text, goal=, color= and color2= (hex, no #), size=sm to xl, done= for the banner text, sound=off. Running two goals? Give the overlay and the dock the same id=. Every option is in the README.
