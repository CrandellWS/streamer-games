How It Works

1

Pick a Game

Click any game above. It opens in your browser with its control panel. Try it there first.

2

Add the Overlay

In OBS add a Browser Source with the game's address plus ?admin=false&bg=transparent. Viewers see only the game, no panel.

3

Open the Remote

Open the same address plus ?view=remote in an OBS Custom Browser Dock (Docks menu) or a second browser window. It shows the full panel, and every button runs in the overlay. The bar turns green when connected.

4

Go Live

Add names and press Start in the remote. The overlay plays the game and shows the winner. Want chat to join? Use Chat Play.

Remote stuck on “waiting for the overlay”? The overlay and the remote must run in the same browser. Open the overlay address in a browser window and add it to OBS with Window Capture, or right-click the Browser Source, choose Interact, and use the keyboard (Space starts most games).
