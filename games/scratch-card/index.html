Scratch Card

Giant scratch-off reveal with metallic surface animation. Match 3 symbols to win. Viewer names as prizes. You run it, chat watches. Free.

How chat plays

  1. Open the game and add names in the admin panel (viewers who typed in chat, subs, anyone).
  2. Press Reveal (or Space). The card scratches itself and three matching symbols is a win.
  3. Press Reset (or R) for a fresh card.

What you need

OBS or any streaming app with a Browser Source. No bot needed: you add names by hand. It is not on Chat Play yet.

Browser Source URL, size 1920 x 1080 (or your canvas size):

https://homeofficestudios.com/scratch-card/?admin=false
