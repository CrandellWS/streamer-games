# Security

## Reporting a problem

Please do not open a public issue for a security problem. Email **william@crandell.ws** with:
- what you found and where, as a file, game or URL
- steps to reproduce it
- what an attacker could do with it

You will get a reply, usually within a few days. Once the problem is fixed, you are welcome to be credited if you would like.

## What is in scope

- The games and pages in this repository, as served at homeofficestudios.com
- Chat Play (`chat/`), including how it handles messages from chat
- Anything that would let chat text run script on a streamer's overlay

The chat relay and the Slot Tools bot are run separately. Report problems with them to the same email.

## Supported versions

Only the current `main` branch is supported. Self-hosted copies should pull updates from it.
