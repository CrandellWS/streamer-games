## Keys that run the games

- **Space** starts most games. **Esc** closes a win screen.
- To add names: open the controller dock (or right-click the game source, choose **Interact**), type names, add them.
- Do not press **G** in an Interact window: it shows the game's control panel on stream.

## If something goes wrong

| Problem | Fix |
|---|---|
| Game source is blank | Right-click the source, **Refresh**. Names you added earlier come back. |
| Controller says "waiting for the overlay" | Use **Interact** on the source instead, keyboard only. |
| Chat play commands get no reply | The game page must be open. Switch to scene 2 for a few seconds, then try again. |
| Emotes not raining | Fine to ignore for the night. Message me after the stream. |
| Anything else mid-stream | Switch to **BRB**, message me, keep talking. |
